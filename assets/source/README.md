# 角色母版来源

`gpt_crab_reference.png` 是通过 Edge（CDP 自动化）在 chatgpt.com 里用图片生成模型产出并下载的原始母版，
1254×1254，纯色绿幕背景 `#00FF00`。

对话记录：https://chatgpt.com/c/6ae104be-1af4-83ee-800f-e0d63309fab0

## 它在项目里的作用

1. 确定角色设计：宽圆蟹壳、奶油色腹甲、两只大而高举的钳子、四对短腿、黑眼白高光、深色描边；
2. 确定配色：母版的橙色系与奶油色被抽出来写进 `tools/crab_art.py` 的调色板；
3. 作为验收对照：`evidence/07_actioncard.png` 的 16 帧应当一眼看出是同一只螃蟹。

## 为什么没有直接裁切这张图

生图模型给的是「一张画」，不是「一致的 16 帧」。同一张网格图里各格比例、腿部姿态、
描边粗细很难对齐，直接切片会得到会抖动的动画。因此这里的做法是：

- AI 负责**设计**（母版图）；
- 代码负责**帧**（`tools/crab_art.py` 按母版的比例与配色重建 16 帧，保证逐帧一致）。

这也是用户明确接受的方案：「可以先用图片设计，再变成像素图，动作做成像素图的变体」。

原图仅作参考保留，不参与运行时渲染（页面只加载 `assets/crab_sheet.png`）。
