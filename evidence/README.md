# 验收证据

本目录是 `requirements.md` 中每条需求、每个验收条件的实测证据。
所有数值都来自真实运行（Edge + 页面内 `window.__probe` 探针 / Python 脚本），不是估算。

| 文件 | 内容 |
| --- | --- |
| `08_final_initial.png` | 打开页面的初始画面（七类海岸元素 + 螃蟹） |
| `03_walk_right.png` `04_walk_left.png` `05_walk_up.png` `06_walk_down.png` | 四向行走中的截图（可见不同朝向的动作帧） |
| `07_actioncard.png` | 动作卡全貌：4 行（下/左/右/上）× 4 帧，带棋盘格透明底 |

| `12_crab_clip.png` / `12_crab_zoom.png` | 角色局部原始像素与 6 倍最近邻放大（检查是否模糊） |
| `probe_game.json` | 四向位移、速度一致性、松键停止、帧序、切向、帧率 |

| `probe_bounds.json` | 四个方向的边界钳制与房屋碰撞 |

## 复现方式

```powershell
# 1. 重建资产并自检动作卡
python tools/build_assets.py
python tools/check_sheet.py

# 2. 启动本地页面
python -m http.server 8099 --bind 127.0.0.1

# 3. 在浏览器控制台或通过 CDP 跑探针（tools/probe_*.js）
```

> 注意：探针依赖 `requestAnimationFrame` 推进，若标签页被切到后台，浏览器会节流导致测量失真。
> `tools/probe_bounds.js` 与 `tools/probe_fps.js` 都带预热自检，未通过会重试。
