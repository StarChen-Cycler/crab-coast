# coast_bgm —— 海岸小游戏背景音乐

海边悠闲向的电子 / 芯片音乐：脉冲波主旋律 + 木琴琶音 + 三角波贝斯 + 轻打击 + 海浪噪底 + 附点回声。
老式休闲小游戏那种「循环着也不烦」的写法，和螃蟹散步的节奏对得上。

## 文件

| 文件 | 说明 |
| --- | --- |
| `coast_bgm.mp3` | 正式用的音乐，44.1 kHz 立体声 160 kbps，40 秒无缝循环，约 781 KB |
| `make_bgm.py` | 合成器源码（纯 numpy，无外部音频素材），改音乐就改这个文件 |
| `bgm.js` | 网页播放器：自动播放 + 右上角开关 + `M` 键切换 + 淡入淡出 |

## 音乐规格

| 项 | 值 |
| --- | --- |
| 调性 / 速度 | F 大调，96 BPM |
| 长度 | 16 小节 = 40.0 秒，末尾尾音与回声折回开头 → **接缝无断口** |
| 结构 | A 段 8 小节（Fmaj9 – Dm9 – ♭Bmaj7 – C6/9 …）+ B 段 8 小节（♭B – C7sus – Am7 – Dm7 – Gm7 – C7 – Fmaj9） |
| 配器 | 主旋律 25% 脉冲波（带颤音）、木琴式正弦琶音、三角波贝斯、双脉冲波铺底、底鼓/沙锤/木鱼、海浪噪底与浪涌 |
| 律动 | 底鼓在 1、3 拍，沙锤走八分并强调弱拍（海岛/巴萨诺瓦味），贝斯 1、2½、3、4½ 拍切分 |
| 母带 | 软削波 + 1.5 kHz 以上轻度高频搁架（+2.5 dB），峰值 0.89，无削波 |

## 重新生成

```powershell
python music/make_bgm.py          # 只输出 MP3（WAV 母版用完即删）
python music/make_bgm.py --wav    # 额外保留无损 WAV 母版（6.7 MB）
```

需要 `numpy` 和 `lameenc`（仅导出 MP3 时用）：

```powershell
python -m pip install numpy lameenc
```

随机种子固定（`default_rng(20261028)`），所以每次生成结果完全一致；没有 lameenc 时会提示并保留 WAV。

## 想改音乐

编辑 `make_bgm.py` 顶部这几个地方就够了：

| 想改什么 | 改哪里 |
| --- | --- |
| 速度 / 长度 | `BPM`、`BARS` |
| 旋律 | `MELODY`：`(起始拍, 时值拍, MIDI音高)`，如 `(0.0, 1.0, 72)` = 第 0 拍起响 1 拍的 C5 |
| 和弦 | `CHORDS`：每小节 `(贝斯根音, 琶音4音, 铺底3音)` |
| 某件乐器音量 | 各 `render_*()` 里的 `gain=` |
| 混响/回声 | `render_delay(SEND, 0.75 * BEAT)` 的延时时间与 `taps` |
| 整体亮度 | `shelf()` 的 `gain_hi`、`f0` |

改完直接重跑脚本即可，不需要动网页。

## 接入方式

`index.html` 末尾已经加了一行：

```html
<script src="music/bgm.js"></script>
```

播放器会自己创建 `<audio loop>`、右上角按钮和 `M` 键开关，音量默认 0.45，静音状态存 `localStorage`。
`bgm.js` 用脚本自身路径定位 `coast_bgm.mp3`，所以整个 `music/` 目录搬到别的项目里也能直接用。

调试接口：

```js
__bgm.toggle()     // 切换静音
__bgm.setMuted(1)  // 直接静音 / 取消静音
__bgm.playing      // 当前是否在响
```

不想要音乐时，删掉 `index.html` 里那一行 script 即可，游戏本身不受影响。

> 小提示：直接双击 `index.html`（`file://`）时，部分浏览器会拦住自动播放 —— 按一下方向键或点一下画面就会响；
> 想更省心就用 `serve.cmd` 起本地服务器。
